# Front-End CDCI

Projeto desenvolvido para estudo e prática de desenvolvimento Front-End, utilizando HTML, CSS, JavaScript e bootstrap.

## Sobre o Projeto

Este repositório reúne interfaces web modernas e responsivas, com foco em:

- Estruturação semântica com HTML5;
- Estilização avançada com CSS3;
- Interatividade utilizando JavaScript;
- Design responsivo para diferentes dispositivos;
- Componentes visuais modernos inspirados em templates profissionais.

O projeto contém duas implementações principais:

### StarBootstrap

Template corporativo com:

- Navbar responsiva;
- Hero Section;
- Serviços;
- Portfólio;
- Sobre a empresa;
- Equipa (Team);
- Formulário de contacto;
- Modais para apresentação de projetos;
- Scroll Spy;
- Menu Mobile;
- Efeitos durante a navegação.

### Techvio

Landing Page moderna com:

- Animações visuais;
- Efeito Vanilla Tilt;
- Sistema de filtragem de portfólio com Isotope;
- Contadores animados;
- Preloader;
- Design profissional para empresas de tecnologia.

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/Front-End_CDCI.git
```

2. Entre na pasta do projeto:

```bash
cd Front-End_CDCI
```

3. Abra o arquivo:

```text
StarBootstrap/index.html
```

ou

```text
Techvio/index.html
```

em qualquer navegador moderno.
